# Glenn Simplified

## What it does

Removes the trees outside the map and replaces the white snow floor with grass so it's much easier on the eyes.

Based on a mod from the [Erinn World forums](https://erinn.world/forum.php?mod=viewthread&tid=21880).

### How it's made

Replaces all the snow textures with grass. Replaces all the tree models with blank files.
