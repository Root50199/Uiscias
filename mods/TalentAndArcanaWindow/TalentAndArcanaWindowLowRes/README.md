# Talent and Arcana Window High Resolution

## What it does

Combines the Talent and Arcana tabs into one. There is some visual jank like the skill icon being wrong when first opening the talent window and link info disappearing when using the ogham tab, but due to how the clients works theres nothing I can do about that. The skill icon is fixed once you use the ogham part of the window and the link info comes back when you reopen the talent window or click the normal tab.
