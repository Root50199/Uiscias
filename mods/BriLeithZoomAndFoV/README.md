# Bri Leith Zoom And FoV

## What it does

Expands zoom out limit dramatically and sets the FoV based on which variant you chose in Bri. Also locks time of day in an effort to address the bright floor bug in Gates 3 and 4. While it helps, it is not enough on its own, so you will want to also use Darker Gate Three Floor to make it so you can still see well when it bugs out into bright mode. With both running, the floor should look about like its normal brightness while bugged out and a bit dark when it's not.

### How it's made

Open the region file in Mabioned and edit the embedded XML from there to change the zoom and FoV.
