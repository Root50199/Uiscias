# Bri Hp Bars 1 And 3

## What it does

Swaps out every boss HP bar in the game with the newer type that displays statuses. Also adds HP bars to certain mobs based on which variant you choose.
This one adds boss HP bars to the first and third Shards of Solace aka halos in Gate 3. Also adds HP bars for Shard of Solace 1 and the Shard of Remorse (Green Room) in Gate 4.

Tip: If you coordinate with a partner you can each run a different variant to be able to see all 3 60% Shards.
