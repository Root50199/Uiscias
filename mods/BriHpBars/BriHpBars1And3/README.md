# Bri Hp Bar1 And3

## What it does

Swaps out every boss HP bar in the game with the newer type that displays statuses. Also adds HP bars to certain mods based on which variant you choose.
This one adds Boss HP bars to the first and third Shards of Solace aka halos in gate 3. Also adds HP bars for Shard of Solace 1 and the Shard of Remorse(Greenroom) in gate 4.

Tip:If you coordinate with a partner you can each run a different variant to be able to see all 3 60% Shards.
