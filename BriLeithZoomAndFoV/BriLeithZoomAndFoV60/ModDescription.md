# Bri Leith Zoom And FoV 60

## What it does:

Expands zoom out limit dramatically and sets the fov based on which variant you chose in bri. Also locks time of day in an effort to address the bright floor bug in gates 3 and 4. While it helps it is not enough on its own, so you will want to also use gatethreefloor to make it so you can still see well when it bugs out into bright mode. With both running the floor should look about like it's normal brightness while bugged out and a bit dark when it's not.

### How it's made:

Open the region file in Mabioned and edit the embeded xml from there to change the zoom and FoV.
