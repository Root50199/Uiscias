# GlennSimplified

Removes the trees outside the map and replaces the white snow floor with grass.

Glenn simplified contains the following files:
data\gfx\scene\dungeon\GlennBearna\prop:
26 blank assets for the trees
data\material\interior\dungeon\GlennBearna:
4 blank dds image files
dg_glennbearna_room03_icefloor01_02.dds
data\material\terrain
9 folders each containing 1 dds image file
